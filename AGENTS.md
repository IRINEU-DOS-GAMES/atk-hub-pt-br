# Fluxo deste projeto

Este é o local fixo da tradução do ATK HUB em Documentos. Atualize esta pasta quando o usuário pedir uma nova tradução; não crie outra pasta de entrega dentro de Documents/Codex.

O usuário autorizou publicar as atualizações deste projeto no seu repositório público do GitHub, com uma Release e o instalador Windows compilado pronto para baixar. Use o remoto já configurado e o endereço em `compatibilidade.json`. Não publique credenciais, backups, arquivos de trabalho nem o software original da ATK.

Após preparar e validar uma atualização compatível, aplique-a também no computador do usuário. Preserve o estado inicial do ATK HUB: se estiver aberto, feche, aplique e reabra; se já estiver fechado, mantenha fechado. O EXE deve solicitar administrador pelo manifesto do Windows. Uma tradução já instalada não exige fechamento nem reinstalação.

Mantenha a verificação da versão e do hash, o backup original e a restauração. Não force pacotes antigos em versões novas. Atualize o pacote atual, guarde a versão datada, publique a Release e informe o link do repositório. O instalador deve direcionar quem precisar de uma versão nova para as Releases do projeto.

O usuário pediu para remover o TXT opcional de checksums dos downloads. Distribua o EXE e o ZIP sem esse arquivo adicional; mantenha as verificações internas de integridade.
